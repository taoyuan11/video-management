# 思源黑体 / Source Han Sans CN

应用内置 Adobe 官方思源黑体简体中文地区子集，版本 **2.005**：

- `SourceHanSansCN-Regular.otf`：正文，字重 400。
- `SourceHanSansCN-Bold.otf`：标题，字重 700。

字体文件原样取自 [adobe-fonts/source-han-sans 的 2.005R 发布标签](https://github.com/adobe-fonts/source-han-sans/tree/2.005R/SubsetOTF/CN)，固定提交为 `6c709ca72d3d7c46ab42ebecc1a26e7d69595a37`，未修改或重新裁剪字形。字体内部家族名为 `Source Han Sans CN`。

字体使用 **SIL Open Font License 1.1**，完整版权与许可见同目录的 [LICENSE.txt](LICENSE.txt)。字体通过 `include_bytes!` 编译进程序，无需联网或安装到系统。便携发布包将本说明及许可证复制至 `licenses/source-han-sans-2.005/`；字体数据已包含在可执行文件内。

Segoe Fluent Icons 继续从 Windows 11 系统字体目录加载，不属于此处随附的字体。
